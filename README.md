# CMF social posts

Daily Instagram / Facebook / Pinterest post images for classicmodernfabrics.com.

- `posts/YYYY-MM-DD.json` — what each post says and which product photo it uses
- `scripts/render.py` + `templates/post.html` — the retro design templates
- `out/YYYY-MM-DD.jpg` — finished images (built automatically by GitHub Actions on every push)

Public image link format: `https://raw.githubusercontent.com/cmf-12/cmf-social-posts/main/out/YYYY-MM-DD.jpg`
